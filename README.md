# متجري — إدارة السوبر ماركت

واجهة عربية للموبايل: المنتجات والباركود، فواتير البيع والشراء، سندات القبض والدفع، كشف حساب الموردين والزبائن، ورصيد الصندوق بالليرة السورية.

الخانات الرقمية تبدأ فارغة. يحوّل التطبيق الأرقام العربية إلى الإنجليزية تلقائياً، ويحافظ على الأصفار داخل الباركود والأرصدة الفعلية.

## حالة التشغيل

ملفات الواجهة في جذر المستودع، وملفات الربط في `apps-script/`. يلزم نشر Apps Script وربط عنوانه لتخزين العمليات في Google Sheets. وضع التجربة يحفظ بياناته في المتصفح فقط.

## تفعيل الربط

1. افتح ملف البيانات الخاص في Google Sheets ثم **Extensions → Apps Script**.
2. انسخ `apps-script/Code.gs` إلى ملف Code، وأنشئ Script باسم Engine من `apps-script/Engine.gs`، وHTML باسم Bridge من `apps-script/Bridge.html`.
3. أظهر ملف manifest من Project Settings واستبدله بمحتويات `apps-script/appsscript.json`.
4. احفظ وشغّل `onOpen` لتفويض المشروع ثم أعد تحميل الشيت.
5. من قائمة **السوبر ماركت → تهيئة وربط التطبيق** أدخل الأصل `https://tmembaradan-hash.github.io` وكلمة مرور عشوائية لا تقل عن 16 حرفاً.
6. **Deploy → New deployment → Web app**، التنفيذ باسمك **Me**، والوصول **Anyone**. يبقى الشيت خاصاً؛ البيانات محمية بتسجيل الدخول في التطبيق.
7. انسخ رابط النشر المنتهي بـ `/exec` إلى `scriptUrl` داخل `config.js`، أو الصقه في شاشة الدخول.
8. فعّل GitHub Pages من **Settings → Pages → Deploy from a branch → main → /(root)** وافتح الرابط الذي يعرضه GitHub.

لا تضع كلمة المرور أو سجلات المحاسبة أو النسخ الاحتياطية في المستودع العام. لا تبدأ العمليات الفعلية قبل ظهور **متصل بجوجل شيت** واختبار الحفظ.

## التحقق والحدود

اجتاز المحرك 25 اختباراً محاسبياً، واختُبر الإدخال الرقمي واحتساب الإجماليات في المتصفح. يلزم اختبار الاتصال الحي وكاميرا الهاتف بعد إتمام النشر. هذه النسخة لا تشمل الضرائب أو تقرير الأرباح أو صلاحيات الموظفين المتعددة أو المرتجعات الجزئية.
